## 本地使用

```bash
npm ci
npm run server
```

生成静态页面：`npm run build`。

- `source/`：文章与页面
- `themes/`：博客主题及资源
- `scaffolds/`：文章与页面模板
- `vue-test/`：独立 Vue 示例项目
