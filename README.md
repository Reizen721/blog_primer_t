## 目录与本地运行

- `client/`：Vue 前端；安装依赖后运行 `npm run dev`，构建使用 `npm run build`。
- `server/`：Express 后端；安装依赖后，在该目录运行 `node app.js`，默认端口为 `1235`。

两个目录分别执行 `npm install`。首次启动前，将 `server/db/blog.example.sqlite3` 复制为同目录下的 `blog.sqlite3`。示例库仅含空表结构，不含本地管理员账号、密码、令牌或运行数据；管理员与内容需自行初始化。
